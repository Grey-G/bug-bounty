# Pay.sh Vertical Explainer Video

This folder contains a 9:16 vertical explainer package for the Superteam Canada Pay.sh video bounty.

## Files

- `pay-sh-explainer.webm` - generated 720x1280 vertical video, formatted for short-form social.
- `cover.png` - vertical cover frame.
- `index.html` - public landing page that embeds the video and transcript.
- `transcript.md` - narration/subtitle script.
- `generate-video.mjs` - deterministic local generator using a browser canvas recorder.

## Core Message

Pay.sh lets AI agents and CLIs discover paid APIs, call them, and settle per request in stablecoins. Solana Subscriptions and Allowances make this safer by giving the agent a bounded spending budget instead of unlimited wallet access.

## Publishing Note

The bounty requires the final video to be published on at least one social channel. This folder provides the ready-to-publish video asset and public GitHub-hosted version, but a true social-channel submission still needs a controlled YouTube/TikTok/Instagram/Facebook account.
