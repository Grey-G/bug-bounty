# Pay.sh Vertical Explainer Transcript

**Title:** Pay.sh turns APIs into agent-readable vending machines.

## Scene 1

Your AI agent needs a paid API.

But stopping for a wallet signature every request kills the workflow.

## Scene 2

Pay.sh gives agents and CLIs a simple pattern:

Discover the API.

Call the endpoint.

Pay per request in stablecoins.

## Scene 3

The missing piece is safety.

You do not want an autonomous agent holding unlimited wallet access.

## Scene 4

Solana Subscriptions and Allowances solve this with bounded delegation.

Approve a small USDC budget.

Set an expiry.

Let the agent operate inside that limit.

## Scene 5

Example:

Give a research agent 5 USDC for 30 minutes.

It buys market data, an LLM summary, and a report export.

If the next call would exceed the budget, it fails before execution.

## Scene 6

For developers, this means:

No custom credit ledger.

No card vault.

No signature prompt per request.

Just programmable spending limits for agentic commerce.

## Scene 7

Pay.sh handles API access.

Solana allowances handle bounded settlement.

Together, they make paid services usable by autonomous software.

Build the API.

Publish the price.

Let agents pay safely.
